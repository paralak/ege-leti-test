# ЕГЭ ЛЭТИ — тест

Локальная программа для прохождения тренировочного варианта ЕГЭ по информатике. Проект запускается в оболочке [phpDesktop Chrome](https://github.com/cztomczak/phpdesktop).

## Установка

1. Скачайте и распакуйте phpDesktop Chrome для Windows.
2. Скопируйте `settings.json` и папку `www` из этого репозитория в каталог phpDesktop с заменой файлов.
3. Запустите `phpdesktop-chrome.exe`.

Ответы сохраняются локально в `www/variant/answers.xml`. Для сохранения у программы должны быть права на запись в эту папку. Чтобы подготовить новую попытку, техспециалист должен закрыть программу и удалить `answers.xml`; при следующем запуске файл будет создан заново. Остаточные `answers.xml.tmp.*` и `answers.xml.bak.*`, если они появились после аварийного выключения, также следует удалить.

При установке варианта с другим `variant_id` прежний файл ответов автоматически переименовывается в `answers.xml.previous.*`, после чего создаётся новая попытка.

Для подготовки программы скопируйте созданную конструктором папку `variant` в `www`, предварительно вынув из неё `answer_key.xml`. Приложенные к заданиям файлы скачиваются непосредственно со страницы теста.

Если `answer_key.xml` останется в ученической сборке либо файлы варианта не пройдут проверку целостности, программа заблокирует запуск и покажет список ошибок.
После окончания времени интерфейс блокируется, а сервер перестаёт принимать ответы после 30-секундного окна финального сохранения.

## Структура

- `settings.json` — настройки окна и встроенного веб-сервера;
- `www/index.php` — интерфейс тестирования;
- `www/download.php` — безопасная выдача приложенных файлов;
- `www/variant/manifest.xml` — сведения о варианте и длительности;
- `www/variant/tasks.xml` — задания;
- `www/variant/files` — прикреплённые файлы;
- `www/variant/answers.xml` — ответы ученика, создаваемые программой.
